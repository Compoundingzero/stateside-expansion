# Frozen continuation research checkpoint

These proposal/audit files record the source-reviewed continuation batch before publication integration. They are historical review evidence, not a second live content store. `src/data/` is authoritative for rendering, current rules, citations and coverage.

The publication owner imported the five authoritative proposal sets (east, west, blocked, territories, origins), reviewed independent findings and made final canonical corrections. Re-importing an old checkpoint can undo later work; the merge script requires a fresh explicit review and must not be included in an ordinary build or deployment. Full fetched source bodies remain in ignored cloud `research/raw/`; tracked sources retain exact short excerpts, dates, access outcomes and hashes.

This batch added 75 published guides. Full counts and remaining gaps are in `docs/coverage-report.json` and `docs/CONTINUATION-RELEASE.md`. The independent sample review is in `INDEPENDENT-REVIEW.md`; Ohio's final procedural limitation and title were corrected during root integration after that note, including its matrix summary.
